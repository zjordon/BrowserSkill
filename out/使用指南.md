# BrowserSkill - 使用指南

> 生成时间: 2026-09-27 · 基于版本 v0.3.1 (commit 8cbcc49)

## 1. 快速开始

### 1.1 组件与支持环境

BrowserSkill 由三部分组成，缺一不可（本地模式）：

| 组件 | 说明 | 支持环境 |
|------|------|----------|
| **`bsk` CLI + daemon** | 命令行工具（daemon 内置，同一二进制） | macOS（Apple Silicon/Intel）、Linux（x64/ARM64）、Windows x64 |
| **浏览器扩展** | 真正的浏览器自动化执行端 | Chrome / Edge，Chromium ≥ 125（其他 Chromium 内核浏览器不保证） |
| **技能（skill）或 DSH 插件** | 教会 agent 如何使用 `bsk` | 12 种 harness：Claude Code、Cursor、Codex、OpenClaw、CodeBuddy、WorkBuddy、Pi、Hermes、Kimi Code 等；DeepSeek Harness 用专用插件 |

### 1.2 安装

**方式一：让 agent 自己装**（推荐）

把这句话发给你的 agent：

```text
Set up browser-skill on this machine by following https://raw.githubusercontent.com/Tencent/BrowserSkill/main/AGENT_INSTALL.md
```

**方式二：手动安装 CLI**

```sh
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/Tencent/BrowserSkill/main/install.sh | sh
export PATH="${BSK_INSTALL_DIR:-$HOME/.local/bin}:$PATH"

# Windows PowerShell（装到 ~\.local\bin）
irm https://raw.githubusercontent.com/Tencent/BrowserSkill/main/install.ps1 | iex

# 验证
bsk --version
```

**连接扩展**：从 [Chrome 商店](https://chromewebstore.google.com/detail/hhcmgoofomhgciiibhipgmgkgnoenaoi) 或 [Edge 加载项](https://microsoftedge.microsoft.com/addons/detail/browserskill/emacgiaaaiojkkpkddmmdfhmokgmnikg) 安装 → 打开扩展 popup → 启用本地连接。

**安装技能**：

```sh
bsk install-skill                 # 交互式：空格选择 harness，回车确认
bsk install-skill --harness cursor --json   # 非交互
bsk install-skill --list          # 查看支持的目标与路径
```

已有安装默认跳过，`--force` 显式替换。其他 harness 可手动复制 `crates/bsk-cli/skill/` 整个目录（含 `references/`）到其技能目录，命名 `browser-skill/`。

**检查连接**：

```sh
bsk doctor
```

doctor 通过后还需**新开一个 agent 会话**确认技能能被发现（doctor 不验证技能发现）。

### 1.3 第一个任务

对你的 agent 说：

```text
Use browser-skill to open https://example.com, summarize the page, and end the browser session when finished.
```

agent 会打开 Agent Window、读取页面、返回摘要并停止会话。支持斜杠命令的 harness 也可用 `/browser-skill`。

**直接用 CLI 体验**：

```sh
bsk session start --no-focus --json    # 记住返回的 session_id
bsk navigate https://example.com --session <id>
bsk observe --session <id>             # 语义观测页面
bsk screenshot --session <id> --out example.png
bsk session stop <id>                  # 用完必须停止（归还借用 tab）
```

## 2. 配置说明

### 2.1 数据目录（BSK_HOME）

默认 `~/.bsk`，可用 `BSK_HOME` 环境变量覆盖（Windows 即 `C:\Users\<用户>\.bsk`）：

| 文件/目录 | 用途 |
|-----------|------|
| `daemon.lock` / `daemon.pid` | 单例锁与 PID |
| `daemon.json` | 发现信息 `{sock_path, pid, ws_port, version}` |
| `daemon.log` | 滚动日志（`bsk logs -f` 跟踪） |
| `audit/` | 操作审计（默认关闭） |
| `record-session.json` 等 | 录制状态与崩溃恢复 |

### 2.2 环境变量

| 变量 | 必需 | 说明 |
|------|------|------|
| `BSK_HOME` | 否 | 覆盖 `~/.bsk` 数据目录（沙箱/多实例场景） |
| `BSK_AUTO_START=0` | 否 | 禁止 CLI 隐式拉起 daemon（宿主托管 daemon 时用） |
| `BSK_DAEMON_WS_URL` | 否 | 构建期默认 `ws://127.0.0.1:52800`，扩展侧连接地址 |
| `BSK_AUTO_UPDATE=off` | 否 | 关闭自更新（CI/评测时用） |
| `BSK_CANCEL_ON_STDIN_CLOSE=1` | 否 | stdin 关闭即取消当前 RPC（Windows 上父进程无法发 Ctrl-C 的替代通道，DSH 插件在用） |
| `BSK_REQUEST_HELP=off` | 否（旧式） | 旧版关闭人类协助请求；**现被扩展端"允许请求人类帮助"开关覆盖，无法绕过** |

### 2.3 daemon 管理

```sh
bsk daemon start [--port 52800] [--foreground] [--mode server]   # 常规由 CLI 自动拉起
bsk daemon restart
bsk daemon stop        # Windows 上为直接终止（无优雅排空）
bsk status             # daemon/浏览器/会话概览
bsk logs -f            # 跟踪日志
bsk doctor             # 连接诊断
```

扩展 popup 中可修改连接端口（保存后已存在会话会被结束并重连）。

### 2.4 扩展端设置

| 设置 | 默认 | 说明 |
|------|------|------|
| 确认后才借用标签 | 开 | agent 接管你现有标签前必须征得同意（overlay 或系统通知） |
| 允许请求人类帮助 | 开 | agent 可请求你完成登录/验证码等步骤 |
| 浏览器名称 | — | 给浏览器实例命名，供 `--browser` 显式选择 |
| 连接端口 | 52800 | 与 daemon `--port` 匹配 |

## 3. 主要功能

### 3.1 会话与 Agent Window

```sh
bsk session start --json                      # 创建会话 + Agent Window
bsk session start --browser "Work profile" --no-focus --json   # 指定浏览器实例
bsk session list
bsk session stop <id>                         # 必须！借用 tab 会归还原窗口
```

要点：Agent Window 共享所选 profile 的登录态，**不是独立账号或安全沙箱**；写操作只作用于 Agent Window 内的标签，除非该标签被显式借用。

### 3.2 页面交互与观测

```sh
# 导航
bsk navigate <url> --session <id>
bsk navigate-back / navigate-forward / reload --session <id>

# 观测
bsk observe --session <id>            # VOM 语义快照（推荐 agent 用）
bsk snapshot --session <id>          # aria 快照 + @eN 引用
bsk get-html --session <id>
bsk console --session <id>           # 控制台缓冲
bsk network --session <id>           # 网络缓冲

# 交互（用 snapshot 返回的 @eN 引用）
bsk click @e1 --session <id>
bsk fill @e2 "text" --session <id>
bsk press Enter / select @e3 "选项" / hover / focus / blur
bsk wheel down 3 / scroll-to @e5 --session <id>

# 标签与窗口
bsk tab list --scope user|agent|all
bsk tab borrow <tab-id> / return    # 借用需用户确认
bsk window resize 1280 800
```

### 3.3 截图（含长截图）

```sh
bsk screenshot --session <id> --out shot.png
bsk screenshot --session <id> --full-page --out page.png   # 自动滚动拼接
```

扩展 popup 的 **Quick Actions → Full-page screenshot** 不需要 agent/daemon 也能用。长截图支持后台 tab（不抢焦点）、分数 DPI；嵌套滚动面板与虚拟列表有已知局限。

### 3.4 网站调试（证据驱动排障）

```sh
bsk debug start --session <id>     # 复现问题前开启捕获
# ... 复现问题（手动或 agent 操作都会被记录）...
bsk debug operations --session <id>      # 操作时间线（请求/console/字段变化/页面变化）
bsk debug request <request-id> --session <id>   # 请求详情（headers/body/耗时/错误）
bsk debug performance / aggregate / duplicates  # 性能与疑似重复请求
bsk debug export --out evidence.json    # 导出证据
bsk debug stop --session <id>
```

规则与重放（任务级、测试假设用）：

```sh
bsk debug rule-add ...      # block / modify / mock（上限 32 条）
bsk debug replay <request-id>       # 同源重放（上限 20 次，可能改服务端数据）
```

扩展内 **Quick Actions → Website debugging** 打开证据工作台；历史保留在浏览器本地（30 天 / 50 条 / 50MiB）。

### 3.5 录制与回放素材

```sh
bsk record start --browser <id>     # 阻塞至用户在浏览器点"结束"（最长 24h）
bsk record stop / export --out trace.json   # 语义轨迹 Trace v3
```

### 3.6 人机协作

```sh
bsk request-help --session <id> --reason "完成登录" \
  --url-contains "dashboard"        # 完成条件：url_contains/url_matches/selector_exists
```

Agent Window 显示帮助请求 overlay；受扩展端"允许请求人类帮助"开关控制。

### 3.7 DeepSeek Harness（DSH）集成

```sh
dsh plugin --profile web add @wxg-prc-cpg/browser-skill-dsh-plugin
dsh --profile web
```

- 会话内 `/browser-skill` 调用；提供 6 个原生工具（`browser_session/page/inspect/interact/tabs/assist`）、任务预览 PiP 浮窗（SSE 实时缩略图、中断按钮）、截图卡片；
- 无需再跑 `bsk install-skill`（插件内含技能）；
- `bsk` 不在默认 PATH 时在插件配置中设 `bskPath`；
- 其他配置：`defaultTimeoutMs`(120s)、`maxSessions`(5)、`lazyTools`、`observationEnabled` 等（经 profile 的 `cordis.patch.yml`）。

### 3.8 远程模式（浏览器在本地、agent 在服务器）

```sh
# 服务器上
bsk daemon start --mode server   # TLS 网关 + 设备配对
```

扩展输入配对 URL（token 在 fragment）完成授权。浏览器主动外连 WSS，本地无需入站端口。**远程模式不支持文件上传/下载**。

### 3.9 文件上传/下载（仅本地模式）

```sh
bsk upload @file-input --path ./local.pdf --session <id>
bsk download @download-link --out ./downloads/ --session <id>
```

CLI 是唯一接触本地路径的组件；下载经原子提交可见；替换已有文件是显式选择。

## 4. 典型工作流示例

### 4.1 用已登录账号读内部文档

```text
Use browser-skill: open the internal wiki in my Work profile browser,
find the release notes for v2.3, summarize them, then stop the session.
```

### 4.2 调查表单保存失败（网站调试）

```text
Use browser-skill to investigate why saving the form on http://localhost:3000 fails.
Start website debugging before reproducing it, inspect the request, response and console,
then export the evidence and end the session.
```

### 4.3 沙箱化 agent（宿主托管 daemon）

沙箱每次命令后清后台进程时：在宿主以固定 `BSK_HOME` 启动 daemon，agent 环境设 `BSK_AUTO_START=0` + 共享同一 `BSK_HOME`。详见 `docs/sandboxed-agents.md`。

## 5. 隐私与安全要点

- Agent Window 共享登录态，**agent 拥有你已登录网站的全部权限**——只交给信任的 agent 与任务；
- 关闭 Agent Window 即停止其任务；扩展停止按钮会中断后续变更操作（`user_aborted`）；
- 网站调试历史存浏览器本地（脱敏有边界，导出件需自行管理）；操作审计默认关闭，存 daemon 主机；
- 无强制云服务、无产品遥测；扩展不直接调用 AI 提供商；
- 明确的隐私政策见 `apps/extension/PRIVACY.md`。

## 6. 更新与维护

```sh
bsk update --yes          # 更新 CLI（会重启本地 daemon）
dsh plugin --profile web update @wxg-prc-cpg/browser-skill-dsh-plugin --latest
bsk --version && bsk status && bsk doctor   # 保持 CLI/daemon/扩展/插件版本匹配
```

- Windows 提示"已暂存更新"时等待替换完成；手动换二进制后需 `bsk daemon restart`；
- 技能（SKILL.md）在 daemon 启动 / session start / doctor 时自动同步，仅当文件未被手改；本地修改与自定义技能被保留；
- 自定义端口/沙箱宿主/远程服务器：`bsk update --yes --no-restart-daemon` 后用原 flags 与 `BSK_HOME` 重启。

## 7. 故障排查

| 症状 | 处理 |
|------|------|
| agent 找不到 `bsk` | 重启 agent 使 PATH 生效，或配置绝对路径 |
| doctor 报扩展未连接 | 扩展 popup 检查启用状态与端口；确认端口与 daemon `--port` 一致 |
| 技能没被发现 | 新开 agent 会话；`bsk doctor` 查看技能同步是否 paused |
| 多浏览器在线报 `multiple_browsers_online` | `bsk browsers` 查看实例，`session start --browser <名称或id>` 显式选择 |
| 沙箱/CI 内 daemon 起不来 | 宿主内 Job 限制；按提示 `--foreground` 或宿主托管 + `BSK_AUTO_START=0` |
| 版本不匹配警告（Skew） | 升级较旧一侧（CLI/扩展/插件需同版本） |
| 日志 | `bsk logs -f`；daemon 日志在 `~/.bsk/daemon.log`（JSON 行） |

## 8. 开发者指南

### 8.1 源码构建

环境：Rust stable（>=1.85，edition 2024）、Node.js 22、`package.json` 声明的 pnpm 版本。

```sh
pnpm install --frozen-lockfile
cargo build --release --locked     # CLI 在 target/release/
pnpm ext:build                     # 扩展产物 apps/extension/dist/chrome-mv3/（加载未打包扩展）
pnpm ext:dev                       # 扩展开发模式
```

### 8.2 测试与检查

```sh
cargo test --workspace --locked    # Rust 全量
pnpm ext:test                      # 扩展 Vitest
pnpm vom:test && pnpm lint         # vom 测试 + Biome/stylelint/DSH 插件检查
pnpm eval:browser validate         # 评测集校验
pnpm eval:browser smoke --suite core --bsk ./target/debug/bsk   # 端到端冒烟
```

### 8.3 评测集（evals/browser）

数据驱动的浏览器能力评测：用例、fixture 页、直接 `bsk` 工作流与断言自动发现，新增用例无需改中央注册表。核心 6 个 `core` 用例 + 1 个种子化 `matrix` 用例；操作清单覆盖 28 种浏览器操作。用户 badcase 需先缩减为合成 DOM 再提交。

### 8.4 本地化贡献

新增语言只需在 `packages/i18n/src/locales/<locale>/` 添加 `common.json` 与 `extension.json`（import.meta.glob 自动注册）。当前支持：en-US、zh-CN、zh-TW、ja-JP、ko-KR、fr-FR、it-IT、es-ES、de-DE、pt-BR。
